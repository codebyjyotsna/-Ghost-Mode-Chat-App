# Ghost-Mode-Chat-App
A real-time, anonymous chat application with disappearing messages, no read receipts, and advanced privacy features. Built with the MERN stack, WebSockets, encryption, and self-destruct timers.

## Features
- **Disappearing Messages**: Messages automatically delete after being viewed or after a set time (e.g., 10 seconds).
- **Anonymous Chatrooms**: Join chatrooms with randomly assigned usernames.
- **No Read Receipts**: Focus on privacy with no tracking of when messages are read.
- **End-to-End Encryption**: Messages are encrypted for secure communication.
- **Typing Indicator**: See when other users are typing without compromising anonymity.
- **Expiring Chatrooms**: Chatrooms automatically delete after a set period (e.g., 1 hour).
- **File Sharing**: Share files securely within chatrooms.
- **Message Reactions**: React to messages with emojis.
